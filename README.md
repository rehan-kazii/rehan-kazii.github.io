# Kazi Rehan Bin Hossen — Portfolio

A responsive static portfolio built with HTML, CSS, and vanilla JavaScript. No build tools, package manager, backend, or paid services are required.

## Files
- `index.html` — page content, metadata, and links
- `style.css` — responsive design, dark/light themes, animations
- `script.js` — theme switch, mobile navigation, reveal animations
- `favicon.svg` — browser icon

## Preview locally (optional)
Open `index.html` directly in a browser. `localhost` is not required. The Google Fonts import requires an internet connection; system fallbacks are provided.

## Publish for free with GitHub Pages
1. Sign in to GitHub as `rehan-kazii`.
2. Create a **public** repository named exactly `rehan-kazii.github.io`.
3. Upload `index.html`, `style.css`, `script.js`, `favicon.svg`, and this README to the repository root. Do not upload the ZIP file as the only repository content.
4. In the repository, open **Settings → Pages**.
5. Under the build/deployment section, select **Deploy from a branch**, choose branch `main` and folder `/(root)`, then save.
6. Wait for the deployment to finish. Your expected public URL is `https://rehan-kazii.github.io/`. It can take several minutes for the first publication.

Official guide: https://docs.github.com/en/pages/quickstart
